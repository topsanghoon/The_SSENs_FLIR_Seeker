# Hardware

The_SSENs_FLIR_Seeker의 기구부(Mechanical) 설계 파일을 관리하는 디렉토리입니다.

## 📂 디렉토리 구조

```
hardware/
├── fusion360/
│   ├── f3d/   # Fusion 360 원본 설계 파일 (.f3d)
│   └── stl/   # 3D 프린팅/뷰어 공유용 STL 파일 (.stl)
├── images/    # 조립 사진, 렌더링 이미지 등
└── README.md  # 현재 문서
```

## 파일 네이밍 규칙
- 파트/어셈블리 단위로 파일명을 통일합니다. 예: `gimbal_mount_v1.f3d` / `gimbal_mount_v1.stl`
- 버전이 올라가면 `_v2`, `_v3` 형태로 뒤에 붙입니다.
- STL은 f3d에서 익스포트한 최신 버전만 유지합니다 (구버전은 필요 시 릴리즈/태그로 보관).
